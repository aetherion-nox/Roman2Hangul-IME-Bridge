# Roman2Hangul IME Bridge

通过罗马字输入韩文的 Windows / AutoHotkey v2 输入辅助工具。它在常规模式下向微软韩语两套式（두벌식）输入法发送对应的键盘事件，而不是粘贴整段韩文。

**当前版本：v0.2.5**  ·  **运行环境：Windows 10/11、AutoHotkey v2**

> 本项目尚未完成 Windows 实机全面测试，属于实验性脚本。请勿在密码框、管理员权限窗口或游戏中使用。

## 安装

1. 安装 [AutoHotkey v2](https://www.autohotkey.com/)（不是 v1）。
2. 下载源码 `Roman2Hangul_IME.ahk`，或从 Releases 下载 ZIP 并解压。
3. 双击运行脚本。
4. 普通组字模式下，将 Windows 韩语输入法切换到两套式与 **한** 模式。

## 快捷键

| 按键 | 行为 |
| --- | --- |
| **F10** | 开启/关闭罗马字转换 |
| **F9** | 在 1959 文教部式与 2000 文观部式之间切换 |
| **F8** | 临时进入/退出 1959 文教部式独立韩文字母模式；退出时恢复原状态 |
| **Enter** | 转换开启时提交当前输入，不将 Enter 传递到原应用（避免触发搜索/换行） |
| **Esc** | 清空尚未提交的缓存 |

普通转换模式支持通过 `-` 指定音节边界，空格也可提交。独立字母模式输入不参与音节组合的字母，例如 `o` → `ㅗ`，`bb` → `ㅃ`，`gg` → `ㄲ`。

## 两套转写规则

- **1959 文教部式**（默认）：更偏向韩文拼写的机械转写，双辅音 `gg/dd/bb/jj/ss` 等可以用于组字。
- **2000 文观部式（RR）**：按现行罗马字字母规则近似反向映射。实际罗马化涉及发音变化，因此无法保证从罗马字唯一恢复原韩文。

## 提示框定位

v0.2.5 尝试利用 Windows 插入光标坐标与 UI Automation 输入控件边界，将提示框定位在输入框**下方**。对于不暴露可访问性坐标的应用，会采用退化定位；不能保证在所有编辑器或浏览器输入控件中精确跟随。
